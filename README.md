# VoiceRS

Голосовые звонки по ссылке. Всё на Rust, без Chromium и веба.

- `server` — UDP-релей (комнаты в памяти, без БД)
- `client` — десктопное приложение (egui + cpal + Opus)
- `common` — формат пакетов и ссылки

## Сборка

Нужны Rust и CMake (для libopus).
Linux: `sudo apt install cmake libasound2-dev pkg-config libopus-dev`

    cargo build --release

## Запуск

Сервер (на VPS, откройте UDP-порт 4000):

    ./target/release/server 0.0.0.0:4000

Клиент: запустить `client`, в поле «Сервер» указать `IP:4000`, нажать «Создать звонок»,
скопировать ссылку `voice://IP:4000/<id>` и отправить друзьям. Они вставляют её в
«Войти по ссылке».

Для локальной проверки: сервер и два клиента на одном ПК, адрес `127.0.0.1:4000`
(наушники обязательны, иначе будет эхо).

## Открытие ссылок кликом

Windows: один раз выполните `client.exe --register`, после этого `voice://...`
открывается в приложении.
Linux: создайте .desktop с `MimeType=x-scheme-handler/voice;` и `Exec=/путь/client %u`.

## Ограничения

- Нет шифрования (кто знает ID комнаты и адрес сервера, тот может войти и слушать).
- Нет эхоподавления и шумоподавления.
- Если запущено два окна по ссылке, откроется второй экземпляр (single instance не сделан).
